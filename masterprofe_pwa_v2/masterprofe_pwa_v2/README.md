# EL MASTER 10K CRM PWA

## Instalación XAMPP
1. Copiar la carpeta `masterprofe_pwa_v2` dentro de `htdocs`.
2. Crear base de datos `revenue_crm`.
3. Importar `sql/schema.sql` desde phpMyAdmin.
4. Revisar credenciales en `config/database.php`.
5. Abrir `http://localhost/masterprofe_pwa_v2/login.php`.
