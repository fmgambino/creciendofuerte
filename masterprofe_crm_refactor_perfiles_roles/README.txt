EL MASTER PROFE CRM - PWA PHP + MySQL

Instalación local XAMPP:
1) Copiar la carpeta del proyecto dentro de htdocs.
2) Crear/importar la base desde sql/schema.sql en phpMyAdmin.
3) Verificar config/database.php:
   DB_NAME = revenue_crm
   DB_USER = root
   DB_PASS = ''
4) Abrir http://localhost/nombre_carpeta/login.php
