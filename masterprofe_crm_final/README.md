# EL MASTER PROFE CRM PWA

PWA Mobile First en PHP + MySQL para CRM de Revenue Sharing: socios inversores, referidos, ganancias del broker, distribuciones, retiros, usuarios, roles, notificaciones, auditoría y WhatsApp configurable.

## Instalación local XAMPP
1. Copiar la carpeta `masterprofe_crm_final` dentro de `htdocs`.
2. Crear base de datos `masterprofe_crm` en phpMyAdmin.
3. Importar `sql/schema.sql`.
4. Editar `config/database.php` si tu MySQL no usa `root` sin contraseña.
5. Abrir: `http://localhost/masterprofe_crm_final/login.php`
